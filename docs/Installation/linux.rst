Linux
=======================================

1. Download rogue

.. code-block:: bash

   git clone https://github.com/InfamousSYN/rogue ; cd ./rogue

2. Setup Python virtual environment

.. code-block:: bash

   python3 -m venv .

3. Run the installer

.. code-block:: bash

   source ./bin/activate
   sudo ./bin/python3 ./install.py
